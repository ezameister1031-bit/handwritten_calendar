# 手書きスケジュール → カレンダー登録システム

手帳やメモに手書きした予定を撮影すると，Gemini API で文字を読み取り，日付・時刻・予定名を取り出して，
カレンダーに取り込めるファイル（.ics）を作るアプリです．修正は画面上の表でも，音声でもできます．

## ファイル構成（説明書との対応）

| ファイル | 内容 | 説明書 |
|---|---|---|
| `app.py` | 画面（Streamlit）．全体の流れ・読み上げ | 2章，3.4，3.5 |
| `preprocess.py` | 画像の前処理（台形補正・影の除去・二値化） | 3.1 |
| `ocr_gemini.py` | Gemini API による手書き文字認識・音声の書き起こし | 3.2 |
| `extractor.py` | 日付・時刻・予定名の抽出ルール | 3.3，表1 |
| `corrections.py` | 修正指示（「3時じゃなくて4時」など）の解釈 | 3.4 |
| `calendar_export.py` | .ics ファイルの作成 | 3.5 |
| `calendar_store.py` | アプリ内カレンダーの予定の保存 | 3.5 |
| `evaluate.py` | 評価用スクリプト | 5章 |
| `tests/test_extractor.py` | 抽出ルールのテスト（API キー不要） | |
| `setup.bat` / `run.bat` | Windows 用のセットアップ・起動 | |

## 1. 準備

### Python
Python **3.11 以上**が必要です．コマンドプロンプトで `python --version` を実行して確認してください．

### Gemini API キーの取得
1. ブラウザで Google AI Studio（https://aistudio.google.com/ ）を開き，Google アカウントでログインします．
2. 「Get API key」→「Create API key」でキーを発行し，コピーします．
   （画面の表記は変わることがあります）
3. キーは他の人に見せたり，ネットに公開したりしないでください．

> 無料枠では，送信した画像などが Google のサービス改善に使われる場合があります．
> テストには，個人情報が含まれないメモを使うと安心です．

## 2. セットアップ（最初の1回だけ）

1. このフォルダの **`setup.bat`** をダブルクリックします．
   必要なライブラリが自動でインストールされます（数分かかります）．
   ※ 仮想環境は OneDrive の同期対象にならないよう，`C:\Users\<ユーザー名>\.venvs\handwritten_calendar` に作られます．
2. `.streamlit` フォルダの **`secrets.toml`** をメモ帳で開き，
   `GEMINI_API_KEY = "ここにAPIキーを貼り付け"` の部分を自分のキーに書き換えて保存します．
   （キーは画面には表示されません．サイドバーに「設定済み」と出れば読み込めています）

## 3. 起動

**`run.bat`** をダブルクリックすると，ブラウザでアプリが開きます（http://localhost:8501 ）．
終了するときは，黒い画面（コマンドプロンプト）を閉じます．

カメラ・マイク・読み上げを使うため，ブラウザは **Chrome か Edge** を使ってください．
初回はカメラとマイクの使用許可を求められるので「許可」を選びます．

## 4. 使い方

1. **画像の入力**：「カメラで撮影」または「画像ファイルを選択」で手書きメモを入力し，「読み取る」を押します．
2. **認識結果**：読み取った行が枠で表示されます（緑：予定として使った行，灰：使わなかった行）．
   右の表で，各行のどの部分を日付・時刻として抽出したかを確認できます．
   「前処理の各段階を見る」を開くと，台形補正などの途中経過が見られます．
3. **確認・修正**：表のセルをクリックして直接直せます．
   音声で直すときは，修正する予定を選んでから「マイクで話す」で録音します．
   - 例：「3時じゃなくて4時」「1時半に変更」「終わりを5時に」「11月6日に変更」「タイトルを研究会に変更」「削除」
4. **登録**：「カレンダーに登録」を押すと，画面下のカレンダーに予定が追加され，登録内容が読み上げられます．
   同じ予定（日付・時刻・予定名が同じ）は二重に登録されません．
5. **カレンダー**：月・週・一覧の表示を切り替えられます．今回登録した予定はオレンジ，以前の予定は青で表示されます．
   予定をクリックすると詳細と「この予定を削除」ボタンが出ます．
   - 「すべての予定を .ics で書き出す」で，Google カレンダー・iPhone・Outlook に取り込めるファイルも作れます．
   - 予定は `data/calendar_events.json` に保存されます（GitHub には上げない設定です）．
     Streamlit Cloud ではアプリが再起動すると消え，使っている人全員で同じカレンダーを共有する点に注意してください．

### 抽出のルール
- 年が書かれていない日付は，基準日（サイドバーで設定．初期値は今日）以降で最も近い日付にします．
- 午前・午後が書かれていない **1〜7時は午後**とみなします（サイドバーで変更可）．
- 日付だけの行は「見出し」とみなし，次の行以降の予定に使います．
  ```
  11/2(月)        ← 見出し
  10:00 授業      ← 11/2 10:00
  ゼミ発表        ← 11/2 終日
  ```
- 日付が見つからない予定は「登録」のチェックが外れた状態になります．表で日付を入れてください．

### 読み取りのコツ
- 白い紙に，1行に1件ずつ「日付　時刻　予定名」の順で書くと安定します．
- 紙全体が写るように，背景（机など）と色が違う状態で撮影すると台形補正がうまく働きます．
- 二値化は初期状態ではオフです．鉛筆の薄い字では精度が下がることがあるため，評価で効果を比べてください．

## 5. テスト

抽出ルールが正しく動くかを確認できます（API キー不要）．
```
%USERPROFILE%\.venvs\handwritten_calendar\Scripts\activate
python -m pytest tests
```

## 6. 評価（説明書の5章）

1. `eval/images/` に手書きメモの写真を入れます（例：`memo01.jpg`）．
2. `eval/truth.csv` に正解の予定を書きます（1行1予定．見本あり）．
   ```
   image,date,start,end,title
   memo01.jpg,2026-10-30,15:00,,ゼミ
   ```
3. 文字認識の正解率も測る場合は，`eval/transcripts/memo01.txt` に正しい書き起こしを書きます（見本あり）．
4. 撮影日を指定して実行します．`--baseline` を付けると「Gemini に抽出までまとめて任せた場合」とも比較します．
   ```
   python evaluate.py --ref 2026-10-28 --baseline
   ```
   前処理の3つの設定（なし／台形補正+影除去／＋二値化）ごとに，文字認識の正解率，予定の再現率・適合率が表示され，
   詳細は `eval/results.csv` に保存されます．認識結果は `eval/ocr_cache.json` に保存されるので，2回目以降は API を呼びません．

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| 「モデル名が使えない可能性」と出る | Google AI Studio で使えるモデル名を確認し，サイドバーの「モデル名」を変更 |
| 「利用回数の上限」と出る | 無料枠の制限です．1分ほど待ってから再実行 |
| 「API キーが正しいか確認」と出る | `secrets.toml` のキーを確認（前後に空白が入っていないか） |
| 台形補正されない | 紙の四隅が写っていないか，背景と紙の色が近い．撮り直すか，台形補正をオフに |
| 読み上げが鳴らない | 画面下の「▶ 読み上げ」ボタンを押す（ブラウザが自動再生を止めている場合があります） |
| マイクが使えない | ブラウザのアドレスバー左のアイコンからマイクを許可．または「文字で入力」を使う |
